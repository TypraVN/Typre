Typre — practice typing code

Typing practice built for programmers. Instead of prose, you type real code: brackets, operators, semicolons and indentation — the characters that actually slow you down while programming.

14 languages, 2,170 snippets

JavaScript, TypeScript, C#, Python, Java, Go, SQL, Bash, C/C++, Rust, HTML, CSS, JSON, and a special-characters drill. Every language has at least 50 snippets for each of the 15, 30 and 60 second runs, served in shuffled order so you never repeat one before finishing a full round — even across page reloads.

What it measures

WPM, CPM, accuracy, raw speed and consistency, plus the characters you miss most often. Earn XP and levels as you practise, unlock achievements, and keep a daily streak. Sign in to submit scores to the leaderboard.

Type your own code

Paste a snippet from your own codebase and practise that instead. Smart quotes, tabs and invisible characters are converted so everything stays typeable.

Race a friend in real time

Send a link and type the same snippet side by side, watching each other's progress live and seeing who finishes first.

Leaderboard

Rank all time, this week or today, filtered by language and run length, or narrow it down to just you and your friends.

IDE shortcuts

A separate drill for VS Code and Vim keyboard shortcuts.

Works offline, free forever

Install Typre to your home screen and keep practising without a network — the whole snippet library ships with the app. No account needed to type, no ads, no payment.
