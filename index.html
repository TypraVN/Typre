Typre — practice typing code

Typing practice built for programmers. Instead of prose, you type real code: brackets, operators, semicolons and indentation — the characters that actually slow you down while programming.

14 languages

JavaScript, TypeScript, C#, Python, Java, Go, SQL, Bash, C/C++, Rust, HTML, CSS, JSON, and a special-characters drill. Over 700 snippets, each 1–4 lines, served in shuffled order so you never repeat one before finishing a full round.

What it measures

WPM, CPM, accuracy, raw speed and consistency over 15, 30 or 60 second runs, plus the characters you miss most often. Sign in to submit scores to the leaderboard.

IDE shortcuts

A separate drill for VS Code and Vim keyboard shortcuts.
