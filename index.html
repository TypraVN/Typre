Questions

What is Typre?

Typre is a free typing trainer for programmers, at typre.dev. It works like an ordinary typing test — timer, WPM, accuracy — except you type real code instead of English prose, in 14 programming languages.

Is it spelled Typre or Typer?

Typre, with the r before the e. The name is "typer" with the last two letters swapped. If you searched for Typer, Typra or type.dev and landed here, this is the site you were looking for.

Is there a typing test for programmers?

That is what Typre is. Ordinary typing tests feed you English prose, so you never practise the keys that actually slow you down while coding. Here every run is real code, and the timer, WPM and accuracy work the same way you are used to.

How do I get faster at typing code?

Practise the characters, not the words. Brackets, operators and punctuation are where most programmers lose time, because they sit on the shifted row and rarely appear in prose. Typre has a drill made of nothing but those characters, plus real snippets in the language you actually write.

Is Typre free?

Yes, and there is no account required to type. Signing in only adds the leaderboard, friends and syncing your XP between devices. No ads, no paid tier.

Which programming languages can I practise?

Fourteen: JavaScript, TypeScript, C#, Python, Java, Go, SQL, Bash, C/C++, Rust, HTML, CSS, JSON, and a punctuation drill. You can also paste code from your own project and type that instead.

Does it work without internet?

Yes. Every snippet ships inside the app, so once it has loaded you can keep practising with no network at all. Only the leaderboard needs a connection.

How is WPM measured?

A word counts as five characters, so WPM is correct characters divided by five, divided by minutes elapsed. Raw WPM counts every keystroke including mistakes, and consistency compares your speed second by second — steady typing scores higher than bursts followed by pauses.
